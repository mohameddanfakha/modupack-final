# ModuPack

Site de démonstration de ModuPack : des cartons d'expédition en une seule pièce, sans colle ni scotch, en trois tailles (S, M, L). Le M se plie en quatre formats pour réduire le vide dans les colis.

ModuPack est une entreprise fictive, créée pour un projet étudiant de création d'entreprise.

- `index.html` : le site (accueil et diagnostic du taux de vide, calculé dans le navigateur ; rien n'est envoyé)
- `logo/` : le logo en SVG
